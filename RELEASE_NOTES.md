# Obojima GM Tools v0.1.0 - Desktop App Release

**Release Date:** January 2026

We're excited to announce the first desktop release of Obojima GM Tools! This standalone Windows application brings all the features you love from the web version, now available offline with persistent local storage.

---

## What's New

### Desktop Application
- **One-click installer** - No technical setup required. Just download, install, and play!
- **Offline access** - Run your game sessions without internet dependency
- **Local SQLite database** - Your data stays on your computer, always accessible
- **Faster performance** - Native desktop app with no browser overhead

### Full Feature Set
- **Character Management** - Track player characters with stats, goals, and portraits
- **Session Planning** - Organize scenes, NPCs, music, and treasure for your sessions
- **Quest Tracker** - Manage active, completed, and failed quests with calendar integration
- **Encounter Builder** - Create and manage combat encounters
- **Companion System** - Track party companions and pets
- **NPC Database** - Organize NPCs with portraits, tags, and relationships
- **Downtime Activities** - Log character activities between sessions

### Content Libraries
- **Potion Crafting System** - Browse Combat, Utility, and Whimsy potions
- **Ingredient Database** - 135+ ingredients with rarity and effects
- **Creature Compendium** - Full creature database with stats and images
- **Magic Items** - Browse and create custom magic items

### Data Management
- **Backup & Restore** - Export your data to JSON and restore anytime
- **Custom Image Uploads** - Add portraits and images for your content
- **Audio Support** - Upload background music for sessions

---

## System Requirements

- **OS:** Windows 10 or Windows 11 (64-bit)
- **Storage:** ~200 MB for installation
- **Memory:** 4 GB RAM recommended

---

## Installation

1. Download the installer (`.exe` or `.msi`)
2. Run the installer and follow the prompts
3. Launch "Obojima GM Tools" from your Start Menu

**Note:** Windows SmartScreen may show "Windows protected your PC" on first run. Click "More info" then "Run anyway" - the app is safe but not yet code-signed.

---

## Known Limitations

- **Windows only** - macOS and Linux versions coming in future releases
- **No auto-updates** - Check back for new versions manually
- **Image uploads stored as base64** - Very large images may increase database size
